# Mi Portafolio Web Profesional

Sitio web personal profesional para mostrarme al mercado laboral, creado con HTML, CSS y JavaScript puro.

## 🌟 Características

- **Quién Soy**: Sección de presentación personal con información de contacto
- **Currículum**: Experiencia profesional y educación detallada
- **Habilidades**: Visualización de habilidades técnicas con barras de progreso
- **Proyectos**: Galería de proyectos con enlaces y descripciones
- **Contacto**: Formulario de contacto funcional
- **Diseño Responsivo**: Adaptado para móviles, tablets y escritorio
- **Navegación Suave**: Scroll suave entre secciones
- **Animaciones**: Efectos visuales modernos

## 🚀 Despliegue en GitHub Pages

Para desplegar este sitio web en GitHub Pages:

1. Ve a la configuración de tu repositorio en GitHub
2. Navega a **Settings** > **Pages**
3. En **Source**, selecciona la rama `main` (o `copilot/create-personal-website` si quieres usar esta rama)
4. Selecciona la carpeta `/ (root)`
5. Haz clic en **Save**
6. Tu sitio estará disponible en `https://tuusuario.github.io/my_web/`

## 📝 Personalización

Para personalizar el sitio con tu información:

1. **Información Personal**: Edita `index.html` y reemplaza:
   - "Tu Nombre" con tu nombre real
   - "tu.email@ejemplo.com" con tu correo electrónico
   - "Tu Ciudad, País" con tu ubicación
   - Enlaces de redes sociales (GitHub, LinkedIn, Twitter)

2. **Foto de Perfil**: Reemplaza la URL de placeholder en la sección "Quién Soy":
   - Sube tu foto a la carpeta del proyecto
   - Actualiza `src="https://via.placeholder.com/300"` a `src="tu-foto.jpg"`

3. **Currículum**: Actualiza las secciones de experiencia y educación con tu información

4. **Habilidades**: Ajusta las habilidades y porcentajes según tu experiencia

5. **Proyectos**: 
   - Actualiza los títulos, descripciones y enlaces de proyectos
   - Agrega imágenes de tus proyectos en lugar de placeholders
   - Actualiza las tecnologías utilizadas

6. **Colores y Estilos**: Modifica `styles.css` para cambiar:
   - Variables CSS en `:root` para cambiar la paleta de colores
   - Fuentes y tamaños de texto
   - Espaciado y diseño
